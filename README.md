Clone the Repository
  git clone https://github.com/kharade-p/data_processing.git
  cd develop

Run the Application
  python jokes_api.py 

Endpoint	Method	Description
/fetch	GET	Fetches and stores jokes
/jokes	GET	Retrieves stored jokes

To view data download sqlite browser as per system from below link 
 https://sqlitebrowser.org/dl/
 After installation choose "Open Database" and select jokes.db file
